AppFrame now composes stable corner controls, a responsive centered stage and a sticky page bar with host breadcrumb, information and action data. Application navigation accepts host header and trigger slots, closes fully without an icon rail, and places account and theme controls in its footer. Drawer exposes an optional measured close-control layout hook and Popover an optional positioning anchor while preserving their omitted defaults and existing overlay lifecycle. The home mark uses the accent silhouette by default; hosts retaining multicolor artwork choose markInk="image".
