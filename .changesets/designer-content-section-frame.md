Add compact, standard and display ContentSection frames with responsive spacing and stacked, split-start and split-end layouts. Split bands place the header and text in a 5/12 column beside a 7/12 companion from tablet-lg, with header, text and visual in reading order. Children can occupy the companion column when media is omitted; header-only splits place supporting copy beside the heading. Empty-string children select the header-only layout and real modules fill their column width. Explicit sizes own padding; the legacy split/mediaSide aliases retain their media-based rendering. Hero accepts display with default as a temporary alias.
