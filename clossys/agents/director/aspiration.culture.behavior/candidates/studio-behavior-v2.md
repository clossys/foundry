## Direction
- Do: Studio production-team members send every visual piece through Designer and pin it in the consumer library; Designer picks from shadcn or an adopted registry and records adaptations, with original work permitted only for consumer assets such as a logo; Writer owns copy, and Publisher assembles only a frame, ordered sections and bindings.
- Refuse: Never hand-roll page JSX or UI files, invent reference provenance, or self-declare clearance; route visual defects to Designer and copy defects to Writer, and treat an item without a reference as a NEED with candidate references until the owner asks to create.
- Signal: Before each Studio handoff, inspect the actual reference source, permitted import, token and data-binding adaptations, consumer pin, and named Designer, Writer or Publisher owner; record missing evidence as a NEED and require browser evidence on the integrated head before ticking checklist rows.
