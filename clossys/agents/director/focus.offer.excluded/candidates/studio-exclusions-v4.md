## Direction
- Not: editing inside Studio, hand-made pages or components, and a hosted service.
- Why: the project ships open packages and public records; running them is the user's own.
- Redirect: run the packages yourself, and ask in the public issues.

## Because
- The packages are public on npm and the repository is public (finding:foundry-public-repo-facts)
- The owner set Foundry on the open-source part of the project (finding:owner-foundry-director-2026-11-11)

## Watch
- If hosted-service requests in public issues > 5 in any quarter, then raise the exclusion with the owner.
