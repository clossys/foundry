## Direction
- Shape: one maintainer over four agents with separate jobs; outside contributors propose changes as public pull requests.
- Decides: the maintainer decides at decide steps; each agent decides inside its own slots; Publisher assembles but never writes or designs.
- Rhythm: Director, then Designer, then Writer, then Publisher, each run ending when its strict check passes.

## Because
- The chain runs in order, with the owner only at decide steps (capability.operation.delivery@7)
- Agents make every change through the system (focus.offer.excluded@3)

## Watch
