## Direction
- Who: developers and founders who already build with coding agents and want their brand, copy and site to come out consistent.
- Situation: they run more than one site or product and want each change checked and on the record.
- Not: teams that want a hosted no-code editor or a drag-and-drop builder; Foundry has neither.

## Because
- The owner set the Foundry Director on the open-source part of the project (finding:owner-foundry-director-2026-11-11)
- Foundry is MIT packages and a CLI on public npm, run from a terminal (finding:foundry-public-repo-facts)
