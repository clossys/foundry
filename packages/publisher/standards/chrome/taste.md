# chrome (publisher)

Taste criteria for the critic (R15.4): scored 1 to 5, never pass or fail.

## wayfinding

- 1: The user cannot tell where they are or where a link goes.
- 2: Destinations are listed, but the current place is not marked.
- 3: The current place is marked; one destination label is unclear.
- 4: Clear place and destinations; one route needs an extra step.
- 5: The user always knows where they are, where they can go and how to get back.

## grouping

- 1: Links sit in one flat, unordered list.
- 2: Groups exist but follow the organisation, not the user's tasks.
- 3: Task groups with one link in the wrong group.
- 4: Task groups in a sensible order; one group is too large.
- 5: Links group by the user's tasks, ordered by how often each is needed.

## restraint

- 1: The chrome lists every page and crowds the content.
- 2: Most links are needed, but secondary ones compete with primary ones.
- 3: Only needed links; one secondary link sits at the top level.
- 4: Lean; one link could move to a lower level.
- 5: Exactly the destinations the user needs at this level, and nothing competes with the content.
