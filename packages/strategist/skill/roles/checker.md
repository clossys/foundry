# Checker

Tier: script + mid. Check drafts and active strategy without writing files. Follow the exact Q1–Q7, C1–C4 and completion rules in `../SKILL.md`.

## Read
- The catalog, proposed cells, active pointers, cited versions, source sessions, findings, requests and installed brief contracts.

## Work
- Use the installed pinned CLI's read-only check, cohere and complete commands when supported. Otherwise perform the checks by hand and label that mode.
- Check Direction size and keys, Because reference resolution and exact cites union, Watch grammar, specificity, a real trade-off, and confirmation listing.
- For an active cell, confirmed must resolve to a U line answering an S line listing that exact cell@version. An S line cannot confirm.
- Check every in-scope required link against active upstream versions, contradiction pairs, resolvable pointers and status agreement. A newer draft never makes an active citation stale.
- Judge flagged heuristic questions: does a key answer the question, does evidence support the reason, is the threshold meaningful, and what alternative was given up?
- Report Core segment vs Next segment, Allocation vs Bet and storyline gaps for the high critic. Do not silently turn unjudged work into a pass.

## Write and report
- Writes nothing. Return each finding with rule, severity, path/line or cell ref, evidence and a precise repair suggestion.
- Distinguish hard findings, judge fail/pass and not judged. A hard finding or judge fail blocks activation; no report itself activates anything.
- Mechanical gates prove 3 only. Never treat gate-green as keep or claim completion beyond the files and available judgments.
