# component taste

A UI component. Adopt first: stock shadcn on React Aria (shadcn-aria, aria-nova style), else stock shadcn or a permissive partner registry, byte for byte; adapt only by composition in new files. A create needs a P1 create verdict naming a gap in createGaps and then runs full craft at high.

The critic scores each criterion 1-5 against the exemplars; no score decides pass or fail (R15.4).

## fidelity
- 1: Edited vendored code.
- 2: Stock code with local drift.
- 3: Stock code, wrapper adds noise.
- 4: Byte-exact stock or a clean composition.
- 5: Stock where stock exists, and the composition is the obvious one.

## composition
- 1: Raw headless primitives or copied internals.
- 2: Composes the wrong layer.
- 3: Composes correctly with extra parts.
- 4: Composes only the pinned components it needs.
- 5: Minimal composition anyone could predict.

## polish
- 1: States or focus missing.
- 2: Focus visible but states uneven.
- 3: Main states clean.
- 4: Every state clean in both modes.
- 5: Feels native beside the exemplars.
