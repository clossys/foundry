# section.app taste

An application section (surface app, including the Studio's own sections): tables, forms, feeds, settings and panels. It composes pinned components and section parts by slot id, reads only pinned theme tokens, states every empty, loading and error case and takes its copy from Writer.

The critic scores each criterion 1-5 against the exemplars; no score decides pass or fail (R15.4).

## density
- 1: Cramped or sparse for its task.
- 2: Density inconsistent across the section.
- 3: Usable density, little tuning.
- 4: Dense where scanning, open where reading.
- 5: Every row and gap fits the task, like the best tools.

## hierarchy
- 1: Actions and data compete.
- 2: Primary action unclear.
- 3: Clear primary action, cluttered secondary.
- 4: Clear primary, secondary and tertiary.
- 5: The next step is obvious without reading.

## clarity
- 1: States are missing or confusing.
- 2: Some states are stated.
- 3: Main states covered, edges unclear.
- 4: Empty, loading and error read plainly.
- 5: Every state tells the user what happened and what to do.

## polish
- 1: Misaligned, inconsistent controls.
- 2: Aligned but uneven spacing.
- 3: Clean in the main state only.
- 4: Clean in every state and both modes.
- 5: Feels finished beside the exemplars.
