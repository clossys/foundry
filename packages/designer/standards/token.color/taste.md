# token.color taste

A colour token slot (a shadcn CSS variable) as a brand value. The Tailwind v4 theme and the shadcn themes are the base a value starts from, never its reason: each candidate realises a pinned Director trait and says which (director:identity.visual.style, director:identity.brand.*). Options for one slot are distinct directions, not shades of one idea.

The critic scores each criterion 1-5 against the exemplars; no score decides pass or fail (R15.4).

## restraint
- 1: Many hues compete; the palette reads as decoration.
- 2: Colour used where weight or space would do.
- 3: Neutral base with an accent, but the accent appears in too many roles.
- 4: Colour only where it carries meaning; the neutral ramp does the work.
- 5: Quiet and exact: colour is rare, so each use is read as a signal.

## temperament
- 1: The value contradicts the pinned visual style.
- 2: A stock reference value with no trace of the brand.
- 3: Consistent with the style but interchangeable with any product.
- 4: Recognisably this brand's temperature and saturation.
- 5: The value could only belong to this brand and states its Director trait plainly.

## mode-balance
- 1: Dark mode is an inverted afterthought.
- 2: One mode loses hierarchy the other has.
- 3: Both modes work but feel like two products.
- 4: Both modes keep the same hierarchy and accent weight.
- 5: Light and dark read as one system, tuned per mode rather than inverted.

## accent-economy
- 1: The accent is reused for links, focus, charts and status alike.
- 2: Accent and status colours collide.
- 3: Roles are separated but the accent is loud.
- 4: One accent, distinct status hues, calm charts.
- 5: Every role has its own job and none borrows another's colour.
