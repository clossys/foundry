# frame taste

A page frame: app shell, site shell, headers, sidebars, sheets and the Studio shell. It composes pinned components and sections by slot id, holds the landmarks and navigation every page shares and reads only pinned theme tokens.

The critic scores each criterion 1-5 against the exemplars; no score decides pass or fail (R15.4).

## orientation
- 1: The user cannot tell where they are.
- 2: Location shown in one place only.
- 3: Location clear, next step unclear.
- 4: Where am I and where can I go are both clear.
- 5: Navigation disappears until needed and never loses the user.

## economy
- 1: Chrome dominates the content.
- 2: Too many persistent controls.
- 3: Balanced, one control too many.
- 4: Chrome serves the content.
- 5: The frame is barely noticed; the content owns the screen.

## polish
- 1: Landmarks or responsive states missing.
- 2: Breaks at one breakpoint.
- 3: Clean at desktop only.
- 4: Clean at every breakpoint and both modes.
- 5: Holds up beside the exemplars.
