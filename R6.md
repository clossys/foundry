## What was found

The 60 package leaves are the unparked leaves of the three trees: 22 layouts, 6 chrome, 27 pages and 5 releases.
**No Publisher package tree holds a publication record.** The planner's "publication: its pages" rule has nothing to
apply to.

Trial placement ran on a temporary copy of the fixture, with `clossys ia publisher/<id> --contract <file> --under
<l1>/<l2> --kind ... --inputs ... --at 2026-11-23T00:00:00Z`. Nothing from the trial is committed.

- **Layouts and chrome:** they place with `--kind page`, the slot/1 family the verb accepts. The slot/2 kind comes
  from the id prefix. Chrome must be placed before layouts: a layout's input `chrome.*` is refused while no slot
  holds it.
- **Pages:** they place with `--kind page --standard page`.
- **Overlap:** `chrome.admin-sidebar` overlaps `chrome.app-sidebar` (same L2 `chrome/sidebars-menus`, equal inputs
  `designer/frames.app-shell`, `designer/frames.app-sidebar` and `writer/frames.app-sidebar.copy`). It would need a
  fixture `--owner-ref` and `--overlap-reason`, for example "admin navigation lists admin page ids, the app
  sidebar lists app page ids". The fixture holds no `clossys/owner-decisions.json` yet, so one would first be made
  with `clossys owner-decision init` and `add`. Nothing was recorded, because the run stopped.
- **`family`:** placement never writes `family`. `clossys migrate contracts` seeds it for Director, Designer and
  Writer only (`CONTRACT_AGENTS`). Adding `publisher` there is the minimum extension the packet allows: the option
  table maps nothing for Publisher, so the family is `{options: 1, varyOn: null, values: []}`.
- **Releases (the block):** `clossys ia publisher/release.<pub> --kind release` is refused with
  `publisher/release.site: no publication site exists (place publisher/publication.site first); a release slot
  belongs to an existing publication`. `releasePlacement` accepts either a placed `publisher/publication.<pub>`
  slot or a `publications` entry in the consumer's `publisher/ia.json`. No clossys verb writes `publications`
  (`--start` writes an empty workspace IA), and no package leaf is a publication.
- **Release inputs:** "a release: its publication" does not hold. The release record names its publication by name
  (`"publication": "site"`), not by slot. The only slots it does reference are `director/focus.reach.geography`
  (`locales.from`) and, for `release.site`, the export pages `publisher/page.terms` and `publisher/page.privacy`.
